# Literature Matrix

**Status:** Focused, non-systematic literature map  
**Last updated:** 2026-10-15

## Purpose and Scope

This matrix records a deliberately small selection of peer-reviewed work relevant to political discussion, platform differences, anonymity, diffusion, and the sentiment tools used in this repository. It is not a systematic review: no database search protocol, screening log, or exhaustive inclusion process was available. Bibliographic metadata and DOI resolution were checked against Crossref on 2026-10-15. The summaries below are a synthesis of publication metadata and abstracts, not a substitute for reading and critically appraising each full paper.

No formal bibliography was found in the checkout. The project materials describe Reddit and X data from the Israel-Hamas war, but do not establish that the studies below were part of the original research design.

## Synthesis and Research Gaps

The selected literature supports treating platform and topic as context for online communication, not as causal explanations by themselves. Prior studies use substantially richer network or diffusion data than the repository's post/comment-level features. The project instead measures readability, lexical diversity, heuristic evidentiary signals, lexicon-based sentiment, and engagement in a single event window.

| Gap in the selected literature / project opportunity                                                                    | Connection to the supplied research question                                                        | What this repository can currently address                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cross-platform comparisons during one contemporaneous event are comparatively less represented in this small selection. | Compare observable Reddit-comment and X-post features within the sampled Israel-Hamas event window. | Descriptive platform-associated differences can be computed. Distinct sampling, record types, and missing link fields limit comparability.                                                                     |
| Anonymity and public-facing identity are not equivalent to measured anonymity.                                          | The question asks whether anonymity moderates language/evidence relationships.                      | Not addressed: account identifiability, anonymity affordances, and user-level exposure are not operationalized. A platform coefficient cannot identify an anonymity effect.                                    |
| Link presence, source credibility, and evidentiary quality are distinct.                                                | The question includes hyperlink density/credibility and evidentiary rigor.                          | The code computes heuristic URL/domain and word-list signals, not verified source quality, truth, or claim-level evidence.                                                                                     |
| Temporal diffusion requires event-level or network traces and a defensible time-series design.                          | The question asks about propagation of extreme sentiment.                                           | The project has timestamps and hourly aggregates, but no verified diffusion cascade or user-to-user pathway. Saved peak-hour and Granger results are not internally consistent enough for a propagation claim. |
| Lexicon sentiment and readability tools require domain-specific validation.                                             | The question refers to extreme sentiment and lexical divergence.                                    | Scores are calculated, but no manually labelled validation set, error analysis, or language-bias study is available.                                                                                           |

Accordingly, the defensible contribution is an exploratory, descriptive comparison of engineered features in these local samples. The current evidence does not test causal effects of anonymity, source credibility in a validated sense, or emotional contagion.
